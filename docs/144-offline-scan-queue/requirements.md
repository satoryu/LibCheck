# #144 オフライン中にスキャンした ISBN を貯めて復帰後に自動検索（レベル3）— Requirements

## Problem Statement

電波の悪い場所（図書館の地下書庫など）では蔵書検索が実行できないため、現状は
バーコードをスキャンしても `/result/:isbn` で検索エラーになるだけである（#145 で
「接続が必要です」の表示は親切になったが、スキャン結果自体は活用されない）。
利用者は「本のバーコードだけ先に読み取っておき、電波が戻ったら自動的に蔵書検索
してほしい」（Background Sync 相当の体験）。

## Requirements

### Functional

- FR-1: オフライン中（`navigator.onLine === false`）にスキャンで ISBN を読み取った
  場合、`/result/:isbn` へ遷移せず、端末ローカルの「保留キュー」に ISBN を保存する。
- FR-2: 保留した直後にその旨（例:「オフラインのため保留しました（N件）」）を
  通知し、スキャン画面に留まって続けて次の本をスキャンできる。
- FR-3: 同一 ISBN はキューに重複登録しない（2度読みしても1件のまま）。
- FR-4: ホーム画面に保留中の検索が存在することを表示する（件数と ISBN リスト、
  各項目の削除操作）。
- FR-5: オンライン復帰（`online` イベント）またはオンライン状態でのアプリ起動時に、
  保留中の ISBN の蔵書検索をフォアグラウンドで自動実行する。
- FR-6: 自動検索が成功した ISBN は検索履歴に保存され（既存の履歴保存と同じ
  分館単位ステータス形式）、キューから削除される。完了は通知で知らせ、
  結果は検索履歴画面から参照できる。
- FR-7: 自動検索が失敗した ISBN はキューに残り、次のオンライン復帰時に再試行される。
- FR-8: 保留キューは端末ローカルに永続化され、アプリ（タブ）を閉じても失われない。

### Non-Functional

- NFR-1: 自動検索は登録図書館の取得完了後に、キュー全体を1回の蔵書検索
  （Calil `/check` は複数 ISBN を受け付ける）として実行し、ポーリング負荷を増幅しない。
- NFR-2: 保留キューはサーバ（D1）には送らない。端末ローカルの一時データであり、
  #74 の永続化レイヤーとは別物として扱う。
- NFR-3: 既存のオンライン時のスキャン→即遷移の体験は一切変えない。
- NFR-4: `npx tsc -b` / `npm test` が緑であること。

## Constraints

- Calil の `/check` はポーリング形式（最大60秒）のため、Service Worker の
  Background Sync（1リクエスト→1レスポンス前提）とは相性が悪い。本イシューは
  Issue 本文の提案どおり「フォアグラウンド再実行」にスコープを落とす
  （SW 側でのバックグラウンド完結・プッシュ通知は将来課題）。
- 蔵書検索プロキシ（`/api/calil/*`）は認証必須（#89）。自動検索はログイン済みの
  アプリ内でのみ実行できる。
- `navigator.onLine` は false positive があり得る（useOnlineStatus のコメント参照）。
  「オンライン判定だが実際は届かない」場合は FR-7 の失敗リトライで吸収する。

## Acceptance Criteria

- AC-1: 機内モード中にスキャンした ISBN が保留リストに残り、リロードしても消えない。
- AC-2: 機内モード解除後、操作なしで自動的に検索が実行され、検索履歴に結果が
  保存される。完了通知が表示される。
- AC-3: 保留中であることがホーム画面で確認でき、不要な保留項目を削除できる。
- AC-4: オンライン時のスキャン動作（即 `/result` 遷移）は従来と変わらない。
- AC-5: 実機（機内モード等）で AC-1〜AC-3 の一連の流れを検証済み。
- AC-6: `npx tsc -b` / `npm test` 緑。

## User Stories

- US-1: 図書館の地下書庫にいる利用者として、電波がなくても気になった本の
  バーコードを次々に読み取っておきたい。後で入力し直したくないからだ。
- US-2: 地上に戻った利用者として、何も操作せずに保留していた本の蔵書状況が
  検索され、履歴から確認できるようにしたい。
- US-3: 間違ってスキャンした利用者として、保留リストから不要な ISBN を
  削除したい。無駄な検索を実行してほしくないからだ。
