# 要件定義: 公開図書館追加ページに離脱防止の案内・ログイン導線を追加する（#167）

## Problem Statement

#158 により `/library/add`・`/library/add/:pref`・`/library/add/:pref/:city` は未認証でも閲覧できるようになり、sitemap.xml にも追加された（Epic #155）。しかし実装済みの3ページ（`PrefectureSelectionPage` / `CitySelectionPage` / `LibraryListPage`）は `SubPageAppBar`（戻るボタン＋タイトルのみ）しか持たず、`AppShell`（ロゴ・ログインボタン・下部ナビ）の外側にある独立ルートのため、以下が画面から一切読み取れない。

- このアプリ（LibCheck）が何をするサービスか
- ログインすると何ができるようになるか

さらに `LibraryListPage` で未ログインのまま「選択した図書館を登録する」を押すと、選択状態を保持する仕組みがないまま `navigate('/')` でランディングページへ丸ごと遷移し、選択していた図書館のチェックが失われる（`src/presentation/pages/LibraryListPage.tsx:48-60`）。ログイン後にユーザーは選択をやり直す必要がある。

Google 検索経由でこれらのページに初めて到達したユーザーにとっては「正体不明な一覧画面」→「登録を押すと脈絡なく別ページに飛ばされ、やり直しになる」という体験になり、インデックスされて流入が増えても、流入直後の離脱（bounce）につながる可能性が高い。

## Requirements

### Functional

1. `/library/add`・`/library/add/:pref`・`/library/add/:pref/:city` の3ページで、未ログイン時のみ、以下を含む案内バナーを `SubPageAppBar` 直下に表示する。
   - アプリ名（LibCheck）
   - 一言説明（何をするアプリか。ログインすると何ができるか）
   - その場でログインできる操作（`GoogleSignInControl`）
2. `LibraryListPage` で未ログインのまま「選択した図書館を登録する」を押した場合、選択中の図書館名を示すインラインのログイン確認 UI（ダイアログ）を開く。全画面遷移はしない。
3. 上記ダイアログでログインが完了したら、選択状態はそのまま保持し、自動的に選択した図書館の登録 API 呼び出し（`addAll`）を実行し、従来どおり `/library` へ遷移する。ユーザーが選択をやり直す操作は不要。
4. 案内バナーの文言は `functions/_shared/routeMeta.js` の対応するルートの `description` と内容の齟齬がないようにする（Google 検索結果のスニペットとページ本文の不一致を避ける）。

### Non-Functional

- 既存の認証まわりの公開インターフェース（`AuthProvider` の `AuthContextValue`、`RootAuthGate`、`publicPaths.ts`）は変更しない。変更の影響範囲をこの3ページの表示・登録フローに限定する。
- モバイル幅（sitemap 経由の流入は多くがモバイル想定）でバナーがリスト表示の大部分を占有しないよう、コンパクトな1〜2行程度に収める。
- 既存の「カーリルへのリンクバック」表示（#156）など、ページ内の他の要素の表示・機能に影響を与えない。

## Constraints

- `AuthProvider` はセッション復元完了まで `user` が一時的に `null` を返す（コールドロード直後の一瞬）。ログイン済みユーザーが直接これらのURLにアクセスした場合、案内バナーが一瞬表示されて消える可能性があるが、今回は許容する（#163 のような機能破壊は起きないことのみ確認する）。
- カーリル API のクォータ消費を増やさない（#155 Epic の完了条件）。今回の変更はクライアント側の表示・導線のみで、新たな API 呼び出しは追加しない。
- Playwright はこの開発環境にインストールできないため、ブラウザでの手動確認は Chrome integration tools を使う。

## Acceptance Criteria

- [ ] 未ログイン状態で `/library/add` に直接アクセス（コールドロード）すると、案内バナーが表示される。
- [ ] 未ログイン状態で `/library/add/:pref` に直接アクセスすると、案内バナーが表示される。
- [ ] 未ログイン状態で `/library/add/:pref/:city` に直接アクセスすると、案内バナーが表示される。
- [ ] `/library/add/:pref/:city` で図書館を1件以上選択し、未ログインのまま「登録する」を押すと、選択状態を保ったままインラインログインダイアログが開く。
- [ ] ダイアログ内でログインすると、選択した図書館がそのまま登録され、`/library` に遷移し、登録結果が確認できる。
- [ ] ログイン済み状態で同じ3ページに直接アクセスしても、機能上の破綻（クエリが固まる等）が起きない。
- [ ] `npm test` / `npx tsc -b` が通る。

## User Stories

- 検索エンジンから `/library/add/埼玉県/狭山市` に初めてたどり着いた未ログインユーザーとして、このページが何のアプリのものかを一目で理解し、興味があればその場でログインできるようにしたい。
- `/library/add/:pref/:city` で図書館を選んで「登録する」を押した未ログインユーザーとして、ログインのために選択をやり直したくない。ログインしたら、選んだ図書館がそのまま登録されてほしい。
