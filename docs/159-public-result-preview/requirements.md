# 要件定義: ISBN 検索結果ページを未ログインでも部分表示する（#159）

## Problem Statement

蔵書検索結果ページ `/result/:isbn` は認証必須で、未ログインではどの URL でもランディング（ログイン誘導）が表示される。そのため、ログインユーザーが URL を他人に送っても、受け取った人には何の本なのかすら伝わらない。また OGP（`og:title` 等）が全ページ共通のため、SNS やチャットに貼っても本の情報が出ない。

本Issueは SEO 施策ではなく、**共有経由で来た人の取りこぼし防止**として行う（ISBN ページを検索エンジンに大量登録する案は #159 で却下済み）。

## 調査結果

- 現状、アプリに共有ボタンは無い（`navigator.share` 等の実装なし）。共有はブラウザで URL をコピーした場合に限られる。
- 書誌情報は OpenBD（API キー不要・CORS 開放）。利用規約は「本の販促・紹介目的に限り使用できる」「キャッシュは可、変更はできるだけ早く反映」（[openBD](https://openbd.jp/)）。共有された本を紹介する表示・OGP はこの目的に当たる。
- 蔵書状況（カーリル `check`）は従来どおりログイン後のみ（#159 の方針。#183 の体験版とは別）。
- 未ログインで表示すると、ログイン済みの人のコールドロード直後（セッション復元中は一瞬 `user === null`）にも未ログイン用の表示が一瞬出る。`AuthProvider` には復元中を表す状態が無い。

## Requirements

### Functional

- **F1. 未ログインの表示**: `/result/:isbn` を未ログインで開くと、ISBN・書影・書名・Amazon とカーリルへのリンク（既存の `BookMetadataCard`）と、案内（LibCheck の説明・その場でログイン・「近くの図書館を探す」→ `/library/add`）を表示する。
- **F2. 蔵書状況はログイン後のみ**: 未ログインでは登録図書館・蔵書状況の取得（保護 API）を行わない。
- **F3. ログイン後はそのまま結果へ**: 未ログインの表示からその場でログインすると、ページを移らずに従来の結果表示（蔵書状況・履歴保存）に切り替わる。
- **F4. 本ごとの OGP**: 配信 HTML の `title`・`og:title`・`og:description`・`og:image` を本ごとの値にする（書名は OpenBD をサーバ側で取得。書影は OpenBD の書影があればそれ、無ければ既定の `og-image.png`）。
- **F5. noindex**: `/result/:isbn` は引き続き `noindex`。sitemap には含めない。canonical は自身に向ける（`noindex` と食い違わないように）。
- **F6. 復元中の表示**: セッション復元中は、未ログイン用の表示ではなく読み込み中を表示する（ログイン済みの人に案内が一瞬出ないように）。
- **F7. 不正な ISBN**: 不正な ISBN の URL は、OpenBD を呼ばず既定の OGP のままにする。

### Non-Functional

- **NF1. 外部 API**: サーバ側の OpenBD 取得は ISBN ごとにエッジでキャッシュする（1日）。タイムアウト（3秒）・失敗時は既定のメタ情報で配信し、ページの表示を妨げない。
- **NF2. 安全性**: 書名など外部由来の文字列は、属性に入れる際にエスケープする（HTMLRewriter の `setAttribute` / `setInnerContent` はエスケープされる）。
- **NF3. 回帰なし**: ログイン済みユーザーの結果表示・履歴保存・計測（#169）は従来どおり。

## Constraints

- 蔵書状況は表示しない（カーリルの利用上限、#159 の却下理由）。
- `/result/:isbn` を sitemap に入れない・インデックスさせない。
- Amazon の書影 URL は OGP に使わない（アプリ内表示とは異なり、SNS 上での配布になるため）。

## Acceptance Criteria

- **AC1**: 未ログインのコールドロードで `/result/<ISBN>` に、書名・書影・案内（ログイン・地域から探す）が表示され、保護 API（`/api/registered-libraries`・`/api/calil/check`）を呼ばない。
- **AC2**: その場でログインすると、同じページで蔵書状況が表示される（`VITE_AUTH_MOCK=true`）。
- **AC3**: ログイン済みのコールドロードで、未ログイン用の案内が表示されない（復元中は読み込み中）。
- **AC4**: 配信 HTML（`curl`）の `title`・`og:title`・`og:description`・`og:image` が本ごとの値で、robots は `noindex`、canonical は自身。
- **AC5**: 不正な ISBN・OpenBD に無い ISBN でも 200 で表示され、既定の OGP。
- **AC6**: `npm test`・`npx tsc -b`・`npm run build` が通る。

## User Stories

- 友人から本の URL を送られた人として、ログインしなくても何の本かが分かり、自分の近くの図書館で借りられるか調べる方法を知りたい。
- 本の URL を送る人として、SNS やチャットに貼ったときに書名と書影が表示されてほしい。
- ログインして使っている人として、結果ページの挙動が変わらないでほしい。
