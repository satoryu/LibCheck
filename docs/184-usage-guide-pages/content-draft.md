## 1. `/guide/bookstore`

- **title**: 本屋で見つけた本が図書館で借りられるか調べる方法 — LibCheck
- **description**: 書店で気になった本を、その場で近くの図書館で借りられるか確かめる方法。本のバーコードを読み取るだけで、登録した図書館の貸出状況と予約ページがわかります。
- **h1**: 本屋で見つけた本が、図書館で借りられるか調べる

**リード**

書店で気になる本を見つけたとき、「買う前に、図書館で借りられないかな」と思ったことはありませんか。LibCheck なら、本の裏表紙のバーコードをスマホのカメラで読み取るだけで、いつも使う図書館にその本があるか、いま借りられるか、予約できるかがわかります。

**h2: こんなときに便利です**

- 気になる本があるけれど、買うかどうか迷っている
- 図書館で借りられるなら、予約して順番を待ちたい
- 近くに図書館がいくつかあって、どこにあるか知りたい

**h2: 調べ方は3ステップ**

1. **いつも使う図書館を登録する** — 都道府県と市区町村を選んで、図書館を登録します。自宅の近くと職場の近くなど、いくつでも登録できます（登録には Google アカウントでのログインが必要です）。
2. **本のバーコードを読み取る** — 裏表紙のバーコードにカメラを向けます。日本の本はバーコードが上下2段になっていることが多く、使うのは「978」で始まる上の段（ISBN）です。下の段を読んだときは、上の段を映すよう案内が出ます。カメラが使えないときは、ホーム画面の「ISBNを入力」から調べることもできます。
3. **結果を見る** — 登録した図書館ごとに「貸出可能」「貸出中」「蔵書なし」などが一覧で表示されます。予約できる図書館には「予約する」ボタンが出て、その図書館の予約ページへ移動できます。

**h2: 書店で使うときのコツ**

- **電波が弱い店内でも大丈夫** — オフラインのときに読み取った本は端末に保留しておき、電波が戻ると自動で調べます。
- **あとで見返せる** — 調べた本は検索履歴に残るので、帰宅してから予約することもできます。
- **アプリのように使える** — スマホのホーム画面に追加すると、アプリのようにすぐ開けます。

**h2: できないこと**

- 書名やキーワードで本を探すことはできません。本のバーコード（ISBN）で調べます。
- 予約の手続きは、各図書館のサイトで行います（図書館の利用者カードなどが必要です）。

## 2. `/guide/barcode`

- **title**: 本のバーコードを読むだけで図書館の予約可否を確認する — LibCheck
- **description**: 本の裏表紙のバーコード（ISBN）をスマホで読み取るだけで、登録した図書館で借りられるか・予約できるかを確認する方法と、結果の見方を説明します。
- **h1**: 本のバーコードを読むだけで、図書館の予約可否を確認する

**リード**

図書館のサイトで本を探すには、書名を入力して、図書館ごとに結果を確かめる必要があります。LibCheck では、本のバーコードを読み取るだけで、登録した図書館すべての貸出状況をまとめて確認できます。

**h2: 本のバーコード（ISBN）とは**

本の裏表紙にあるバーコードには、その本を表す ISBN（国際標準図書番号）が入っています。日本の本の多くはバーコードが上下2段になっていて、上の段が「978」（一部は「979」）で始まる13桁の ISBN、下の段は価格や分類を表すコードです。LibCheck が使うのは上の段です。

**h2: 読み取り方**

1. ログインして、ホーム画面の「バーコードでスキャン」からカメラを起動します。
2. 上の段のバーコードを、画面の枠に合わせて映します。
3. 読み取れると、自動で結果の画面に移ります。

暗い場所では、画面右上のボタンでライトを点けられます（端末によっては使えない場合があります）。カメラが使えないときは、ホーム画面の「ISBNを入力」から調べることもできます。

**h2: 結果の見方**

| 表示 | 意味 |
|---|---|
| 貸出可能 | いま借りられます |
| 館内のみ | 図書館の中で読めます（貸出はできません） |
| 貸出中 | ほかの人が借りています。予約できる場合があります |
| 予約中 | 予約が入っています |
| 準備中 | 貸出の準備中です |
| 休館中 | 図書館が休館しています |
| 蔵書なし | その図書館にはありません |

「予約する」ボタンが表示された図書館は、その図書館の予約ページへ移動できます。予約の手続きは図書館のサイトで行います。

**h2: うまく読み取れないとき**

- 下の段を読んでいる場合は「978で始まる上段を映してください」と案内が出ます。上の段だけを枠に入れてください。
- 明るい場所で、バーコードが画面いっぱいにならない距離で映すと読み取りやすくなります。
- カメラの使用を許可していない場合は、ブラウザの設定で許可してください。

## 3. `/guide/nearby-libraries`

- **title**: 近くの複数の図書館をまとめて登録して一度に確認する — LibCheck
- **description**: 自宅の近くと職場の近く、隣の市の図書館など、使える図書館をまとめて登録すれば、本のバーコードを1回読み取るだけで全部の図書館の貸出状況を確認できます。
- **h1**: 近くの図書館をまとめて登録して、一度に確認する

**リード**

自宅の近くの図書館、職場や学校の近くの図書館、隣の市の図書館――使える図書館がいくつもあると、どこに本があるかを1館ずつ調べるのは大変です。LibCheck では、使う図書館をまとめて登録しておけば、バーコードを1回読み取るだけで全部の図書館の状況がわかります。

**h2: 市区町村をまたいで登録できます**

図書館は都道府県・市区町村ごとに選んで登録します。別の市区町村や別の都道府県の図書館も、同じように追加できます。分館も1館ずつ選べるので、実際に足を運ぶ図書館だけを登録できます。

**h2: 1回の読み取りで、全部の図書館を確認**

本のバーコードを読み取ると、登録したすべての図書館の状況が一覧で表示されます。どの図書館なら今すぐ借りられるか、どこなら予約できるかを見比べて、行きやすい図書館を選べます。

**h2: どの端末でも同じ内容**

登録した図書館と検索履歴は、ログインしているアカウントに保存されます。スマホで登録した図書館を、パソコンからもそのまま使えます。

**h2: 図書館を使える条件について**

住んでいる市区町村以外の図書館は、在勤・在学の人や近隣の自治体の住民が使える場合があります。利用できる条件は図書館ごとに異なるため、各図書館のサイトで確認してください。

**h2: 対応している図書館**

全国の公共図書館・大学図書館など、約7,500館に対応しています（図書館の情報はカーリルの提供によります）。お住まいの地域の図書館は、都道府県から探せます。
