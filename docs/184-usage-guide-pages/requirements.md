# 要件定義: 用途を説明するページを2〜3本追加する（#184）

親Issue: #181

## Problem Statement

#182・#183 で地域ページは「この地域の図書館に対応していることを案内し、その場で試せるページ」になった。しかし検索から入ってくるのは主に「〇〇図書館 蔵書検索」のような、公式サイトを探す検索であり、アプリ本来の用途（本のバーコードで、図書館で借りられるか・予約できるかを調べる）に合う検索から入ってくる入口がない。

アプリの使い方そのもの（「本屋で見つけた本が図書館で借りられるか調べる」「バーコードを読むだけで予約可否を確認する」など）を説明するページを置き、用途に合う検索からの流入と、登録への導線を作る。

## Requirements

### Functional

- **F1. ページ**: 使い方を説明するページを3本追加する（URL・見出し・本文は `content-draft.md` で確認を受けたもの）。
  1. 本屋で見つけた本が図書館で借りられるか調べる（`/guide/bookstore`）
  2. 本のバーコードを読むだけで図書館の予約可否を確認する（`/guide/barcode`）
  3. 近くの複数の図書館をまとめて登録して一度に確認する（`/guide/nearby-libraries`）
- **F2. 各ページの構成**: パンくず（トップ > ページ名）、h1、本文（h2 の節）、行動を促す欄（「都道府県から図書館を探す」→ `/library/add`、地域ページで1冊試せることの案内）、ほかの使い方ガイドへのリンク、フッター（プライバシーポリシー・利用規約）。
- **F3. メタ情報**: ページごとに固有の title・meta description・canonical（拡張子なしの URL）・OGP。robots は index。
- **F4. 構造化データ**: `BreadcrumbList` と `Article`。`HowTo` は使わない（Google は2023年に HowTo のリッチリザルトを廃止）。
- **F5. 内部リンク**: トップページ（未ログイン時のランディングと配信 HTML）と、市区町村ページ（配信 HTML と SPA）から3本へリンクする。
- **F6. sitemap.xml**: 3本を追加する。

### Non-Functional

- **NF1. JS 非実行の HTML**: 本文はすべて配信 HTML に含める。
- **NF2. 文言**: アプリにない機能（キーワード・書名での蔵書検索、アプリ内での予約手続きなど）があるように読める表現は使わない。できないことは明記する。
- **NF3. 見た目**: アプリの配色トークン（`KC_COLORS`）に合わせ、スマホ幅で読みやすくする。
- **NF4. 保守性**: 3本で共通の見た目は共有の CSS ファイルにまとめる。

## Constraints

- 既存の URL（`/library/add/...`）は変更しない。
- `google-site-verification` の meta タグは削除しない（トップの `index.html` のみに存在。新しいページは静的 HTML で、所有権確認には影響しない）。
- 個人向けページを `noindex` にする既存の仕組みは維持する。
- 「〇〇図書館 蔵書検索」を狙う最適化はしない。
- アプリ内のリンクは `.html` 付きにする（拡張子なしの URL は本番の Pages にしか存在せず、ローカルの Vite では 404 になるため。本番は 308 で拡張子なしに転送される）。canonical と sitemap は拡張子なしの URL にする。

## Acceptance Criteria

- **AC1**: 3本の配信 HTML（`curl`、JS 非実行）に、h1・本文・パンくず・行動を促す欄・ほかのガイドへのリンクが含まれる。
- **AC2**: 3本の title・description・canonical（拡張子なし）が固有で、robots が index。
- **AC3**: 3本の JSON-LD が妥当（`BreadcrumbList` + `Article`）。
- **AC4**: トップページと市区町村ページの配信 HTML に、3本へのリンクが含まれる。SPA の描画にも含まれる。
- **AC5**: sitemap.xml に3本が含まれる。
- **AC6**: 本文にアプリにない機能を連想させる表現（「蔵書検索」「キーワードで検索」等）がない（テストで確認）。
- **AC7**: `npm test`・`npx tsc -b`・`npm run build` が通る。ブラウザ（スマホ幅）で読みやすく表示される。

## User Stories

- 本屋で気になる本を見つけた人として、買う前に近くの図書館で借りられるかを手早く確かめる方法を知りたい。
- 図書館のサイトで書名を入力して探すのが面倒な人として、バーコードを読むだけで済む方法を知りたい。
- 自宅と職場の近くなど複数の図書館を使う人として、まとめて確認する方法を知りたい。
- 運営者として、アプリの用途に合う検索から、登録につながる流入を得たい。
