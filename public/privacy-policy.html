プライバシーポリシー

最終更新日: 2026年10月11日

satoryu（以下「開発者」）は、Web アプリケーション「LibCheck」（以下「本アプリ」）における ユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 本アプリについて

LibCheck は、書籍の ISBN バーコードをスキャンまたは手動入力することで、 ユーザーが登録した図書館における蔵書の貸出状況を確認できる Web アプリです。 図書館の登録・検索履歴などの機能の利用には、Google アカウントでのログインが必要です。 地域ごとの図書館の案内ページでは、ログインせずに書籍 1 冊の貸出状況を試しに確認できます（以下「体験版」）。 図書館情報の検索には、カーリル株式会社が提供する カーリル図書館 API を利用しています。

2. 取得する情報

2-1. Google アカウント情報（ログイン）

ログイン時に Google（Google Identity Services）を通じて、以下の情報を取得します。 パスワードを本アプリが受け取ることはありません。

  • 氏名（表示名）
  • メールアドレス
  • プロフィール画像の URL
  • Google アカウントの識別子（sub）

これらは利用者の認証と、登録図書館・検索履歴を利用者ごとに紐づけて保存するために使用します。

2-2. カメラ

書籍の ISBN バーコードをスキャンするため、カメラの使用許可を求めます。 カメラの映像はブラウザ内でのバーコード認識にのみ使用され、画像・動画として保存または送信されることはありません。

2-3. サーバーに保存するデータ

以下のデータは、ログインした利用者に紐づけて、開発者が管理するサーバー（Cloudflare D1 データベース）に保存されます。 これにより複数の端末で同じ登録内容・履歴を利用できます。

  • 登録図書館: 利用者が登録した図書館の名称・システム ID など
  • 検索履歴: 検索した ISBN・検索日時・各図書館の蔵書状況

2-4. 体験版の利用回数（乱用防止）

体験版の乱用を防ぎ、図書館 API の利用上限を守るため、体験版を使った接続元の IP アドレスを、 元の値に戻せない形（秘密の値を加えたハッシュ値）に変換し、利用回数とともにサーバー（Cloudflare D1 データベース）に保存します。 IP アドレスそのものは保存しません。この記録は利用回数の制限にのみ使用し、最大 2 時間で削除します。

2-5. Cookie

ログイン状態を維持するため、開発者が発行するセッション用 Cookie を 1 つ使用します （HttpOnly・Secure・SameSite=Strict）。これは認証目的のみに使用し、広告・追跡には使用しません。

また、利用状況の把握（サービス改善）のため Google アナリティクス 4 の Cookie （_ga 等）を使用します。これは訪問の集計・機能の利用状況の分析のみに使用し、 広告目的では使用しません（Google シグナル・広告機能は有効にしていません）。 ブラウザの設定や Google アナリティクス オプトアウト アドオン により無効にできます。

3. 外部サービスへの送信

本アプリは、機能提供のため以下の外部サービスと通信します。

サービス送信する情報目的
Google（認証） ログイン時の認証情報 Google アカウントでのログイン
Cloudflare（配信・保存） 本アプリの配信、上記 2-3・2-4 のデータ保存 ホスティングおよびデータベース
カーリル図書館 API ISBN・図書館のシステム ID・都道府県名・市区町村名・API キー（個人を特定する情報は含みません） 蔵書確認・図書館検索
OpenBD ISBN（個人を特定する情報は含みません） 書名・書影の取得
Cloudflare Web Analytics（アクセス解析） 閲覧ページ・リファラ・国・ブラウザ種別などの集計情報（Cookie を使用せず、個人を特定できる情報は収集しません） アクセス状況の把握（サービスの改善）
Google アナリティクス 4（アクセス解析） 閲覧ページ・リファラ・おおよその地域・ブラウザ種別などの集計情報と、アプリ内の操作イベント（バーコード読み取りの成功、検索結果の表示、共有された本のページの表示、体験版の実行と結果の種別、図書館の予約ページ・Amazon へのリンクのクリック、および検索した図書館の件数）。書名・ISBN・図書館名・個人を特定できる情報は送信しません 利用状況の把握（サービスの改善）
Sentry（エラー監視） エラー発生時の技術情報（エラー内容・発生箇所・ブラウザやOSの種類など。個人を特定する情報・検索内容のご本人との紐づけは含みません） 不具合の検知・修正（サービスの品質向上）
Amazon ISBN（リンク・書影の生成に使用。個人を特定する情報は含みません） 書影の表示および商品ページへのリンク

本アプリは Amazon.co.jp を宣伝しリンクすることによって紹介料を獲得できる Amazon アソシエイト・プログラムの参加者です。各サービスにおける情報の取り扱いは、 Google・ Cloudflare・ カーリル 各社のポリシーをご参照ください。

4. 情報の利用目的

  • Google アカウントによる認証とログイン状態の維持
  • 図書館の蔵書・貸出状況の検索・表示
  • 登録図書館の管理・表示（利用者・端末間での同期）
  • 検索履歴の保存・表示（利用者・端末間での同期）
  • アプリの動作改善

5. 情報の第三者提供

開発者は、以下の場合を除き、取得した個人情報を第三者に販売・提供しません。

  • 法令に基づく場合
  • 人の生命・身体・財産の保護のため、本人の同意を得ることが困難な場合

上記 3 の外部サービスとの通信は、本アプリの機能提供に必要な範囲での利用です。

6. データの保管と削除

  • 検索履歴: アプリ内の履歴画面から個別または一括で削除できます。削除はサーバー上のデータにも反映されます。
  • 登録図書館: アプリ内で登録を解除すると、サーバー上のデータからも削除されます。
  • ログアウト: セッション Cookie を削除します。サーバー上の登録図書館・検索履歴は保持され、再ログインで再び利用できます。
  • 全データの削除・アカウントに関するお問い合わせ: 下記のお問い合わせ先までご連絡ください。

7. 広告・アナリティクス・エラー監視

本アプリは広告を表示していません。

アクセス状況の把握のため、Cloudflare Web Analytics を利用しています。 これは Cookie を使用せず、個人を特定できる情報を収集しない、プライバシーに配慮した計測です （収集されるのは閲覧ページ・リファラ・国・ブラウザ種別などの集計情報のみ）。

サービスの品質向上のため、エラー監視サービス（Sentry）を利用しています。 アプリでエラーが発生した際に、上記 3 の表に記載の技術情報を送信します。 Sentry における情報の取り扱いは Sentry のプライバシーポリシーをご参照ください。

8. 未成年者のプライバシー

本アプリは 13 歳未満のお子様を対象としておらず、13 歳未満の方から意図的に個人情報を収集することはありません。

9. 本ポリシーの変更

開発者は、必要に応じて本ポリシーを変更することがあります。 変更後のポリシーは、本ページに掲載した時点から効力を生じるものとします。
